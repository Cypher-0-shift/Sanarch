   ✓ Start frontend (Expo Metro)

┌──────────────────────────────────────────────────────────────┐
│  STEP 3: OPEN ON YOUR DEVICE                                 │
└──────────────────────────────────────────────────────────────┘

   In the Metro bundler window:
   
   Press 'a' → Open on Android emulator
   Press 'i' → Open on iOS simulator (Mac only)
   
   OR scan QR code with Expo Go app on your phone


┌──────────────────────────────────────────────────────────────┐
│  IMPORTANT: FIRST TIME SETUP                                 │
└──────────────────────────────────────────────────────────────┘

   1. Configure frontend/.env:
      
      For Android Emulator:
      EXPO_PUBLIC_API_URL=http://10.0.2.2:8000
      
      For Physical Device:
      EXPO_PUBLIC_API_URL=http://YOUR_IP:8000
      
      Find your IP: Run 'ipconfig' in terminal

   2. Enable Firebase Phone Auth:
      - Go to Firebase Console
      - Authentication → Sign-in method
      - Enable Phone provider

   3. Build for Android (Firebase requires dev build):
      cd frontend
      npx expo run:android

┌──────────────────────────────────────────────────────────────┐
│  TROUBLESHOOTING                                             │
└──────────────────────────────────────────────────────────────┘

   Backend not responding?
   → Check: http://localhost:8000/health
   → Run: cd backend && docker-compose restart

   Frontend can't connect?
   → Check EXPO_PUBLIC_API_URL in frontend/.env
   → Use 10.0.2.2 for emulator, your IP for device

   Firebase errors?
   → Ensure google-services.json is in android/app/
   → Run: npx expo run:android (not expo start)

   Clear cache:
   → cd frontend && npx expo start --clear
