     • Start Metro bundler
     • Open the app automatically

The Docker build is failing due to network timeout downloading Python packages.

FIXES:

Fix 1: Retry the build (network might be slow)
   ────────────────────────────────────────────────────────────────────────────
   
   cd backend
   docker-compose down
   docker-compose up --build
   
   Sometimes it just needs a retry.


Fix 2: Increase Docker timeout
   ────────────────────────────────────────────────────────────────────────────
   
   Add this to backend/Dockerfile and backend/Dockerfile.worker:
   
   Before the line: RUN pip install --no-cache-dir -r requirements.txt
   Add: ENV PIP_DEFAULT_TIMEOUT=300
   
   This increases timeout from 60s to 300s.


Fix 3: Use local backend without Docker
   ────────────────────────────────────────────────────────────────────────────
   
   cd backend
   
   # Activate virtual environment
   .\venv\Scripts\activate
   
   # Install dependencies
   pip install -r requirements.txt
   
   # Run migrations
   alembic upgrade head
   
   # Start backend
   uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
   
   Then update frontend/.env:
     EXPO_PUBLIC_API_URL=http://10.0.2.2:8000

TROUBLESHOOTING:

"I don't have Android Studio"
  → Download from: https://developer.android.com/studio
  → Install with default settings
  → Open it and let it download Android SDK

"adb devices shows no devices"
  → Make sure emulator is fully booted (you see Android home screen)
  → Try: adb kill-server && adb start-server
  → Then: adb devices

"Build fails"
  → Delete node_modules: rmdir /s /q frontend\node_modules
  → Reinstall: cd frontend && npm install
  → Try again: npx expo run:android

"Still getting Firebase error"
  → Make sure you're NOT using Expo Go
  → You MUST run: npx expo run:android (builds native app)
  → NOT: npx expo start (uses Expo Go)
