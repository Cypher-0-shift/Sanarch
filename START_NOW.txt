└──────────────────────────────────────────────────────────────────────────────┘

  STEP 1: Check Status
  ────────────────────────────────────────────────────────────────────────────
  
    Double-click:  check-status.bat
    
    This will verify:
      • Android SDK installed
      • Node.js installed
      • Environment files exist
      • Current configuration


  STEP 2: Start Android Emulator
  ────────────────────────────────────────────────────────────────────────────
  
    Option A: Use Android Studio
      1. Open Android Studio
      2. Click "AVD Manager" (phone icon)
      3. Click ▶️ next to an emulator
      
    Option B: Connect Physical Device
      1. Enable USB debugging on phone
      2. Connect via USB
      3. Run: adb devices
      
    Verify device is connected:
      adb devices
      
    You should see a device listed.


  STEP 3: Build and Run App
  ────────────────────────────────────────────────────────────────────────────
  
    Double-click:  build-and-run.bat
    
    This will:
      • Clean previous builds
      • Generate native Android folders
      • Link Firebase native modules
      • Build the app (5-10 minutes first time)
      • Install on your device/emulator
      • Start Metro bundler
      • Open the app automatically
      
    ⏱️  First build: 5-10 minutes
    ⏱️  Subsequent builds: 1-2 minutes

┌──────────────────────────────────────────────────────────────────────────────┐
│  ❓ TROUBLESHOOTING                                                          │
└──────────────────────────────────────────────────────────────────────────────┘

  "No devices found"
    → Start Android emulator or connect device
    → Run: adb devices
    
  "Build failed"
    → Delete node_modules: rmdir /s /q frontend\node_modules
    → Reinstall: cd frontend && npm install
    → Try again: build-and-run.bat
    
  "Firebase error"
    → See FIX_FIREBASE_ERROR.md
    → Firebase requires development build (not Expo Go)
    
  "Backend connection failed"
    → Check frontend/.env has correct API URL
    → Currently using: https://api.sanarch.in/v1
